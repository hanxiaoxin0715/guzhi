# AI 小说工作坊 (Novel Workshop)

这是一个专门为小说创作者设计的 AI 辅助创作工具，基于飞彩工作室 (FEICAI Studio) 架构定制。

## 核心功能

- **AI 大纲生成**: 根据小说标题、题材和梗概，自动生成分卷分章大纲。
- **章节内容生成**: 根据细纲自动扩写章节正文，支持 2000-3000 字深度创作。
- **写作工作台**: 沉浸式写作体验，集成 AI 续写和润色优化功能。
- **角色管理**: 提取并管理小说中的角色档案、性格设定及成长轨迹。
- **剧本转换**: 一键将小说正文转换为适合制作分镜的影视剧本格式。

## 快速开始

1. 进入 `app` 目录
2. 安装依赖 (如果尚未安装):
   ```bash
   npm install
   ```
3. 运行开发服务器:
   ```bash
   npm run dev
   ```
4. 访问 [http://localhost:3000](http://localhost:3000) 即可开始创作。

## 独立运行说明

本项目已从飞彩工作室主分支独立出来，专注于小说创作功能。所有的飞彩官方功能入口已移除，默认进入小说工作坊模式。
